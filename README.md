# 🍎 Калькулятор калорий

Минималистичный веб-калькулятор калорий и БЖУ с трекером блюд, избранным и быстрым добавлением. Работает полностью в браузере — без сервера, без регистрации, без интернета.

---

## ✨ Возможности

### 🎯 Расчёт дневной нормы
- Формула Миффлина–Сан Жеора (BMR)
- Учёт пола, возраста, роста, веса и уровня активности
- Три режима: **Похудение** (−400 ккал), **Поддержание**, **Набор** (+350 ккал)
- Автоматический расчёт целей по БЖУ (30/30/40)

### 🍽 Учёт блюд
- Добавление еды вручную (название, калории, Б/Ж/У)
- **Календарь по дням** — переключение между датами стрелками
- **Избранное** — сохранение часто используемых блюд
- **Дублирование, редактирование, удаление** любого блюда
- **Undo при удалении** — тост с кнопкой «Вернуть» на 5 секунд

### ⚡ Быстрое добавление
- **96 готовых продуктов** в 8 категориях: фрукты, овощи, белок, молочка, гарниры, блюда, напитки, снеки
- Автоматические теги при добавлении (мясо, рыба, завтрак и т.д.)
- Мгновенное добавление в текущий день одним кликом

### 🧮 Калькулятор по граммовке
- Вводишь КБЖУ на 100 г с упаковки + вес порции → получаешь точные цифры
- Кнопка «→ в форму» переносит результат в форму добавления

### 📊 Визуализация
- Кольцо прогресса — процент от дневной цели
- Прогресс-бары по белкам, жирам, углеводам
- **График тренда** за 7 или 30 дней с линией цели

### 🏷 Теги
- 15 предустановленных тегов с уникальными цветами
- Свои теги через поле ввода
- Клик по тегу на блюде → фильтрация списка

### 💾 Данные
- **Автосохранение** в localStorage браузера
- **Экспорт** всех данных в JSON-файл
- **Импорт** из резервной копии

### 🎨 Интерфейс
- Тёмная и светлая темы с автосохранением выбора
- Космический фон: плавающие звёзды и ореолы
- Кастомный скроллбар
- Плавные анимации везде
- Полностью адаптивный дизайн (десктоп / планшет / телефон)

## 🚀 Как запустить

### Локально
1. Скачай или склонируй репозиторий
2. Открой `index.html` в браузере

Готово. Никаких сборщиков, зависимостей и `npm install`.

### GitHub Pages (публикация в интернете)
1. Создай репозиторий на GitHub и загрузи все файлы
2. Зайди в **Settings → Pages**
3. В разделе **Source** выбери: `Deploy from a branch` → `main` → `/(root)` → **Save**
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_НИК.github.io/calorie-calculator/`
